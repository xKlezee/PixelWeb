How Guides work

Overview, reference and history have different jobs.

Keeping these roles separate prevents contradictory values and makes future balance changes much easier to document.

Know what changed.

No invented mechanics.

If a value has not been verified against the current implementation or an approved configuration, Guides will mark the subject as incomplete instead of presenting an estimate as live behavior. That rule applies especially to stats, rewards, balance values, item effects and unlock requirements.
