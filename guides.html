Documentation contract

How a guide becomes authoritative.

Old documentation can tell us what to investigate. Only current evidence determines what we publish as live behavior.

Verified

Current behavior

Traced to the current implementation, configuration or an explicitly approved source of truth.

Planned

Approved direction

Useful roadmap context, but never represented as content already available to players.

Unknown

Not enough evidence

The value stays unpublished instead of being guessed from an old guide, memory or estimate.

One fact, one source.

A requirement, unlock, reward, stat or mechanic gets one canonical data owner. Other pages may explain the concept, but they should not maintain independent copies of the same value.
