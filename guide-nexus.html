Nexus & Instances.

Nexus is Pixel Network's separate endgame destination. This reference documents the reconciled encounter catalogue and the canonical account-based access and difficulty model without implying that every source-staged correction has already reached production.

Catalogue reconciled · September 2026— Instance encounters— individual bosses
Reference status is intentionally split.

The encounter catalogue was reconciled against source and live configuration. Later Raphael phase-continuity/source reconciliation work was validated in source but was still awaiting deployment at the last recorded verification. Pixel Guides keeps those two confidence levels separate.

01 / Access model

One account threshold defines Nexus access.

The canonical public model treats access separately from the later milestones that expand Instance difficulty.
