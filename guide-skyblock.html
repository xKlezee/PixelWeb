Island progression reference

Skyblock, without overclaiming.

Pixel Skyblock has persistent island play, upgrades, banking and its own quest surface. Collaboration features are still partial, so this reference keeps them visibly separate instead of presenting unfinished behavior as available.

Source verifiedPartial system disclosedPlayer-facing claims bounded
01 / Current capabilities

The current player-facing surface is intentionally clear.

These capabilities belong to the canonical public Skyblock model. Team invitations, member management and promotion stay outside the current list until the complete player flow is available.

02 / Island foundations

Your island is meant to persist and grow.

This reference focuses on gameplay outcomes: keeping an island, progressing it, using its economy systems and following island-specific objectives.

Skyblock remains separate from the four-World route.

Its quests and island progression form their own route. They are not a universal questline required to move from Overworld through Winter or into Nexus.

03 / Collaboration status

Collaboration remains partial.

Team-oriented functionality is not presented as generally available until players have a complete, supported way to use it. The current reference therefore separates those features from the stable island experience.

Public Skyblock copy avoids promises such as “Invite friends” or “Build together” until collaboration reaches the same availability standard as the current island features.

State: partial
04 / Availability labels

Current, partial and planned mean different things.

The labels on this page describe what a player can rely on today versus an area that exists but is not yet complete enough to present as a finished feature.

05 / Documentation confidence

Current foundations have source evidence; collaboration remains partial.

The evidence level and completion state stay separate. Source evidence supports the current island capabilities, while any future server/live-client promotion still requires representative runtime and client validation.
