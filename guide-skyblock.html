Island progression reference

Skyblock, without overclaiming.

Pixel Skyblock has a real persistent island foundation, progression systems and economy-backed island operations. Collaboration code also exists, but its player-facing wiring is not complete; this reference keeps those states separate instead of marketing unfinished controls as available.

Source-qualifiedPartial system disclosedPlayer-facing claims bounded
01 / Current capabilities

The stable public surface is intentionally narrow.

These capabilities are kept in the canonical public network model. Team invitations and promotion are not included in this list until their reachable player path is complete.

02 / Source foundation

The island is a persistent gameplay domain, not a decorative menu.

Source inspection establishes dedicated world lifecycle, database and economy paths. This page describes those foundations at player-reference level without exposing internal infrastructure details that do not help gameplay.

Skyblock remains separate from the four-World route.

Its quests and island progression form their own route. They should not be presented as a universal questline required to move from Overworld through Winter or into Nexus.

03 / Partial surface

Collaboration foundations exist; availability does not.

The current source contains meaningful invite and membership logic, but missing command/menu wiring prevents Guides from describing that code as a complete player feature.

The overview and canonical data model now follow this same boundary, so public marketing no longer says “Invite friends” or “Build together” as a currently verified capability.

State: partial
04 / Documentation contract

Reachability is part of feature completeness.

A professional reference must prove that the player can actually reach a feature, not merely that a class, button label or unfinished manager exists in source.

05 / Documentation confidence

Source-qualified today; promotion requires stronger evidence.

The island lifecycle and supporting paths are source-backed. This guide will not be promoted to an unqualified server/live-client state until collaboration wiring and representative client behavior are independently validated.
