Marketplace

Collections you can inspect, not just thumbnails.

Rendered from Pixel's Minecraft model assets

Marketplace is a separate Pixel Network category for cosmetic collections. The current catalogue follows the same acquisition → rotation → collection structure used by the game content, with interactive Minecraft-model inspection where a registered item exposes a model.

Catalogue hierarchy

The web follows the content structure instead of flattening it.

Items are grouped by how they belong together. The first imported source is the Luminite armor collection from Loot Box Rotation 01.

Publication rule

Pack asset ≠ Marketplace item.

The resource pack contains additional Luminite artwork, but this page deliberately publishes only entries that have a corresponding Nexo item definition. That keeps the website aligned with the actual game-content registry as future rotations are imported.
