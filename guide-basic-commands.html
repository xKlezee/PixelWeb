Player shortcuts

Basic Commands.

This is intentionally a concise player reference, not a dump of every registered command. Staff, moderation, administration and unfinished command paths are excluded.

Player-facing onlyCurrent source/configNot an admin command list
Store

/store

Open the current in-game Store/shop surface.

Use /store when you want the player-facing store flow. Store-facing purchases can use Pixels where that active surface defines them.

Skyblock

/is

Open the Skyblock island menu.

The island menu is the main entry point for current Skyblock actions. Collaboration and member-management controls remain partial, so this command reference does not promise unfinished team actions.

Open Skyblock guide →
Collection

/bestiary

Open the Bestiary.

The current Bestiary has active boss presentation/tracking. Categories whose gameplay trackers or content are not ready remain unavailable or Coming Soon rather than being documented as complete.

Talismans

/codex

Open the Talisman Codex.

Aliases currently registered for the same Codex surface include /cdx and /talismancodex.

Open Talisman Codex guide →
Talismans

/bag

Open the Talisman Bag / jewelry equipment surface.

Current aliases include /talismans, /talismanbag and /jewelry.

Why this list is deliberately short

A command only belongs here when its current player-facing purpose is established. Unfinished, staff-only or ambiguous command paths stay out of the basic reference until their behavior is ready to publish.
